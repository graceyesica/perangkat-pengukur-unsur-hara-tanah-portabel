# Portable IoT-Based Soil Nutrient Measurement Device

An academic group project focused on developing a portable Internet of Things (IoT) device for measuring soil nutrient levels and monitoring soil conditions.

## About the Project

The Portable Soil Nutrient Measurement Device is designed to help users measure and collect soil condition data using an integrated sensor and IoT technology.

The device measures several soil parameters, including:

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Soil pH
- Temperature
- Moisture
- Electrical Conductivity (EC)

The system uses an ESP32 microcontroller to process sensor readings and communicate with an Android application. Measurement data can be stored locally and synchronized with the backend when an internet connection is available.

## Project Objectives

- Develop a portable device for measuring soil nutrient levels.
- Collect soil condition data through IoT technology.
- Support offline data collection and online synchronization.
- Provide a platform for viewing and managing measurement data.

## System Overview

The system consists of the following components:

1. **Soil Sensor:** Measures soil nutrient levels and other soil parameters.
2. **ESP32:** Processes sensor data and handles communication.
3. **Android Application:** Receives measurement data and supports local data storage.
4. **Backend API:** Handles data synchronization and communication.
5. **Database:** Stores soil measurement records.
6. **Web Dashboard:** Displays measurement data and location information.
